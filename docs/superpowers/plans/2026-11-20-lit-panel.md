# Lit Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lift the sidebar and phone menu into a top-lit panel and calm the page grain.

**Architecture:** CSS only. New surface tokens in `app/globals.css`, one shared `.lit-panel` class replacing
`bg-panel`/shadow on the two panels, page vignette as a fixed layer next to the existing grain layer.

**Tech Stack:** Next.js 16, Tailwind 4, plain CSS custom properties.

**Spec:** docs/superpowers/specs/2026-11-20-lit-panel-design.md

## Global Constraints
- No accent colour; greys only. No layout, content, navigation or motion changes.
- Grain stays a self-transparent noise layer (no blend modes: iPhone Safari ignores them).
- Matched grain on standard (1x) and sharp (2x+) screens.

## Review Focus
- Light theme: panel must read as a lifted white card, not vanish into #fafafa.
- Current-page pill and hover rows must still stand out on the lighter panel.
- Phone menu sheet uses the same surface; its slide animation must be unaffected.
- Vignette must sit behind content and never catch taps (pointer-events none, z-index -1).
- Reduced motion / no JS: purely static CSS, nothing to break.
